# Cobblemon Ecosystems: Untamed

**Alex's Mobs compat for Cobblemon Ecosystems · Compat do Cobblemon Ecosystems com o Alex's Mobs**

Em construção. Um add-on do [Cobblemon Ecosystems](https://github.com/Lx-xz/cobblemon-ecosystems) para o
**Alex's Mobs (Unofficial Port)** do Raguto: os bichos selvagens do Alex's Mobs dão lugar a Pokémon, que herdam o que
eles faziam (Pokémon formiga nos formigueiros, Tropius dando banana...).

O plano está no [ROADMAP.md](ROADMAP.md).

### Requisitos
- Minecraft 1.21.1 · NeoForge
- Cobblemon 1.8+ e Kotlin for Forge
- Cobblemon Ecosystems 1.1+
- Alex's Mobs: o Unofficial Port 1.22+ (com a Citadel) ou o Alex's Mobs Continued 2.2+ (com a CodxLib)

## Development · Desenvolvimento

```bash
./gradlew build            # build/libs/cobblemon-ecosystems-untamed-<version>.jar
./gradlew runClient        # test client (needs ../base built first: Cobblemon Ecosystems)
```
